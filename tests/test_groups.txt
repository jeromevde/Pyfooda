# Pyfooda test groups
# Format: group_name | food_item_1 | food_item_2 | ...
#
# Each group defines items that SHOULD land in the SAME output group.
# Confusable pairs — groups whose name-token Jaccard >= 0.30 — are
# auto-detected and tested for correct SEPARATION.
# This means one file covers both merge and split behaviour.
#
# Scoring (scripts/score_groups.py):
#   merge_check  per group with ≥2 items: all items in same output group?
#   split_check  per confusable pair: items in DIFFERENT output groups?
#   score = 1 - (failures / total_checks)
#
# Items must be present in tests/test_fooddata.csv (or whichever CSV
# is passed to run_aggregation.py --mode test).
